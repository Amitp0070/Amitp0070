## 🚀 Selected Engineering Work

The following projects represent systems I've worked on professionally. Their source code may not be publicly available.

### 1. AI-Powered Social Media Automation

**Technologies:** Python, FastAPI, React, PostgreSQL, Gemini, NVIDIA FLUX, Meta Graph API

- Developed workflows for trend discovery, AI-generated content, image generation, and social media publishing.
- Integrated LLM-based content generation, embeddings, RAG, and vector search.
- Implemented background processing, WebSockets, retries, and external provider integrations.

### 2. AI Voice Call Analytics

**Technologies:** Python, FastAPI, PostgreSQL, pgvector, Redis, ARQ, Gemini, ElevenLabs

- Built a system to transcribe and analyze sales and support calls.
- Evaluated agent performance across eight assessment areas and generated actionable feedback.
- Used hybrid RAG and vector search to combine historical call information with behavioral data.
- Implemented staged background processing, retries, and idempotent jobs.

### 3. WhatsApp Unified Inbox

**Technologies:** Python, FastAPI, PostgreSQL, Redis, React, Meta WhatsApp Cloud API, WebSockets

- Developed a multi-tenant messaging platform with a shared team inbox, CRM functionality, role-based access, and analytics.
- Implemented webhook processing, customer matching, message deduplication, and real-time updates.
- Added JWT authentication, RBAC, encrypted credentials, PII masking, and retry handling.
- **Performance improvement:** Reduced Conversations API response time from approximately 15 seconds to 2.5 seconds by optimizing database queries, eliminating N+1 queries, and introducing caching.

### 4. Enterprise ERP & Business Integrations

**Technologies:** PHP, Laravel, PostgreSQL, MySQL, Eloquent ORM, SAP integrations

- Developed and maintained enterprise application modules and business workflows.
- Contributed to ERP modernization from a Core PHP implementation to a Laravel-based version.
- Built REST APIs, authentication, middleware, and role-based access control.
- Integrated SAP and EFRIS for business data exchange and workflow automation.
