## 🧠 Engineering Principles

- **Reliability first:** Design backend workflows to handle failures and external API errors predictably.
- **Security by design:** Apply authentication, authorization, input validation, and appropriate access controls.
- **Database performance:** Use efficient queries, appropriate indexes, and caching where they improve real workloads.
- **Maintainable architecture:** Separate responsibilities and keep business logic understandable.
- **Practical AI:** Use LLMs, retrieval, and automation to solve defined problems rather than adding AI without a clear purpose.
